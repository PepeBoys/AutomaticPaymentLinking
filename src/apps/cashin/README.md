# Приложение cashin - Работа с приходными ордерами

## Описание

Модуль `cashin` реализует работу с приходными ордерами (cash in orders) МойСклад. Приложение построено на базе `payment_base` и переиспользует всю базовую функциональность через наследование.

## Основные компоненты

### 1. REST API Endpoint
```
┌────────────────────────────────────────────────────────────────┐
│                     GET /{payment_id}                          │
├────────────────────────────────────────────────────────────────┤
│  Получить информацию о приходном ордере                        │
│                                                                │
│  Path Parameters:                                              │
│    • payment_id: str  → ID приходного ордера в МойСклад        │
│                                                                │
│  Response: CashInResponse                                      │
│    • id: str                                                   │
│    • accountId: str                                            │
│    • name: str                                                 │
│    • moment: datetime                                          │
│    • applicable: bool                                          │

│    • agent: dict                                               │
│    • organization: dict                                        │
│    • paymentPurpose: str                                       │
│    • operations: list[LinkedOperation]                         │
│    • meta: MetaRef                                             │

```

```python
from apps.cashin.domain.value_objects import CashInFilter
from datetime import datetime, timedelta

# Создать фильтр
filter = CashInFilter(
    agent_id="agent_456",

filter_string = filter.to_moysklad_filter()

## Интеграция с системой webhook
```
┌────────────────────────────────────────────────────────────────┐
│              РОЛЬ В АВТОМАТИЧЕСКОЙ ПРИВЯЗКЕ                    │
└────────────────────────────────────────────────────────────────┘

WebhookHandler при обработке события "cashin CREATE":

1. Получает приходный ордер через CashInService
2. Ищет подходящие документы (заказы, счета, отгрузки)
3. Привязывает приходный ордер к документам
4. Применяет статусы (опционально)
5. Переносит проект и канал продаж (опционально)

┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│  МойСклад → Webhook → WebhookService → WebhookHandler           │
│                                               │                 │
│                                               ▼                 │
│                                        CashInService            │
│                                               │                 │
│                          ┌────────────────────┼────────────┐    │
