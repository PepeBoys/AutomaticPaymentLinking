# Приложение cashout - Работа с расходными ордерами

## Описание

Модуль `cashout` реализует работу с расходными ордерами (cash out orders) МойСклад. Приложение построено на базе `payment_base` и переиспользует всю базовую функциональность через наследование. Расходные ордера используются для учета исходящих наличных платежей.

## Интеграция с системой webhook
```
┌────────────────────────────────────────────────────────────────┐
│              РОЛЬ В АВТОМАТИЧЕСКОЙ ПРИВЯЗКЕ                    │
└────────────────────────────────────────────────────────────────┘

WebhookHandler при обработке события "cashout CREATE":

1. Получает расходный ордер через CashOutService
2. Ищет подходящие документы (заказы поставщику, счета, приемки)
3. Привязывает расходный ордер к документам
4. Применяет статусы (опционально)
5. Переносит проект и канал продаж (опционально)

┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│  МойСклад → Webhook → WebhookService → WebhookHandler           │
│                                               │                 │
```
