# Приложение hooks - Управление webhook и автоматическая привязка платежей

## Описание

Модуль `hooks` реализует систему управления webhook-подписками МойСклад и автоматическую привязку входящих/исходящих платежей к документам (заказы, счета, отгрузки, приемки).

## Основные компоненты

### 1. REST API Endpoints

#### Управление подписками
```
GET  /webhooks/status              # Получить статус всех вебхуков
POST /auto-link-toggle             # Включить/отключить автопривязку
POST /update-link-settings         # Обновить настройки привязки
```

#### Обработка событий
```
POST /moysklad/webhook             # Прием webhook от МойСклад
GET  /statuses                     # Получить список статусов
```

## Паттерны проектирования

### 1. Strategy Pattern (Webhook Operations)
```
┌──────────────────────────────────────────────────────────────────┐
│                    WebhookOperation (ABC)                        │
├──────────────────────────────────────────────────────────────────┤
│  + execute() -> WebhookOperationResult                           │
└────────────────────────────────┬─────────────────────────────────┘
                                 │
                    ┌────────────┴────────────┐
                    │                         │
                    ▼                         ▼
     ┌──────────────────────────┐  ┌──────────────────────────┐
     │ EnableWebhookOperation   │  │ DisableWebhookOperation  │
     ├──────────────────────────┤  ├──────────────────────────┤
     │ + execute()              │  │ + execute()              │
     │   • find existing        │  │   • find existing        │
     │   • create if missing    │  │   • update enabled=false │
     │   • update enabled=true  │  │   • return result        │
     │   • return result        │  │                          │
     └──────────────────────────┘  └──────────────────────────┘
                    │                         │
                    └────────────┬────────────┘
                                 │
                                 ▼
            ┌────────────────────────────────────────┐
            │    WebhookOperationFactory             │
            ├────────────────────────────────────────┤
            │  + create_operation(enabled: bool)     │
            │    -> WebhookOperation                 │
            │                                        │
            │    if enabled:                         │
            │      return EnableWebhookOperation()   │
            │    else:                               │
            │      return DisableWebhookOperation()  │
            └────────────────────────────────────────┘
```

### 3. Unit of Work Pattern
```
┌──────────────────────────────────────────────────────────────────┐
│                        UnitOfWork                                │
├──────────────────────────────────────────────────────────────────┤
│  - _session: AsyncSession                                        │
│  - _webhooks: WebhookRepository | None                           │
│  - _committed: bool                                              │
├──────────────────────────────────────────────────────────────────┤
│  @property                                                       │
│  + webhooks -> WebhookRepository                                 │

│                                                                  │
│  + commit() -> None                                              │
│      # Commit transaction                                        │
│                                                                  │
│  + rollback() -> None                                            │
│      # Rollback transaction                                      │
│                                                                  │
│  + __aenter__() -> UnitOfWork                                    │
│  + __aexit__() -> None                                           │
│      # Auto-rollback on exception                                │
└──────────────────────────────────────────────────────────────────┘

                         ИСПОЛЬЗОВАНИЕ:

    async with uow:
        webhook = await uow.webhooks.get_by_payment_type(...)
        webhook.activate()
        await uow.webhooks.update(webhook)
        await uow.commit()
        # При ошибке: автоматический rollback
```
