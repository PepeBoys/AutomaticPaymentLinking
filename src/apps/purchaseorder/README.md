# Приложение purchaseorder - Заказы поставщикам

## Описание

Модуль `purchaseorder` реализует работу с заказами поставщикам в системе МойСклад. Это **наследник** модуля `payable_document_base`, добавляющий минимальный специфичный функционал для работы с заказами на закупку товаров у поставщиков.

**Ключевое назначение**: Поиск и привязка заказов поставщикам к входящим платежам (paymentout) для автоматической сверки оплат по закупкам.

**ВАЖНО**: Заказ поставщику (purchaseorder) = заказ НА ЗАКУПКУ товаров, противоположность заказу покупателя (customerorder).


## Примеры использования

### Получение заказа через REST API
```python
# GET /purchaseorder/order_123
response = await client.get("/purchaseorder/order_123")

# Response:
{
  "id": "order_123",
  "name": "00042",
  "sum": 100000.0,
  "payedSum": 60000.0,      # Уже оплатили 60к
  "shippedSum": 40000.0,    # Получили товара на 40к
  "agent": {"meta": {"href": ".../counterparty/supplier_456"}},  # Поставщик!
  "moment": "2024-01-15T10:30:00Z"
}
```

### Поиск заказов для платежа
```python
# GET /purchaseorder/search/for-payment?agent_id=supplier_456&payment_sum=40000&by_sum=true
response = await client.get(
    "/purchaseorder/search/for-payment",
    params={
        "agent_id": "supplier_456",
        "payment_sum": 40000.0,
        "by_sum": True
    }
)

# Response:
{
  "orders": [
    {
      "id": "order_123",
      "name": "00042",
      "sum": 100000.0,
      "payedSum": 60000.0,
      "unpaidAmount": 40000.0,    # ← Точно совпадает с платежом!
      "isFullyPaid": false
    }
  ],
  "total": 1
}
```

### Использование domain методов
```python
from apps.purchaseorder.services.purchaseorder_service import PurchaseOrderService

service = PurchaseOrderService(auth_service)
order = await service.get_by_id("order_123")

# Domain методы
if not order.is_fully_paid():
    unpaid = order.get_unpaid_amount()
    print(f"Осталось оплатить: {unpaid} руб")
    # Осталось оплатить: 40000.0 руб

if order.is_partially_paid():
    print(f"Заказ частично оплачен: {order.payed_sum}/{order.sum}")
    # Заказ частично оплачен: 60000.0/100000.0

# Проверка отгрузки
if order.shipped_sum is not None:
    unshipped = order.get_unshipped_amount()
    print(f"Осталось получить: {unshipped} руб")
```
